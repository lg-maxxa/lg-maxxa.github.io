# lg-maxxa.github.io

## ProximaChat — Offline P2P Chat App 🦇

A production-quality cross-platform mobile app (Android & iOS) for offline peer-to-peer communication using Bluetooth and Wi-Fi Direct.

👉 **[See the app in `/proximachat/`](./proximachat/README.md)**

### Features
- Discover nearby users via Bluetooth & Wi-Fi
- Friend request workflow (send → accept/decline)
- WhatsApp-like chat UI with message bubbles, ticks, timestamps
- 100% offline — no internet required
- Professional icons8 assets integrated (bat animation, sent, attach, chat icons)
